# AGENTS.md

Правила для ИИ-агентов, работающих с этим репозиторием.

## Что это за проект

Статический сайт-визитка Станислава Чернышева (MADTeacher): книги, научные
публикации, каналы, площадки поддержки. Хостинг – GitHub Pages,
продакшен https://madteacher.github.io (репозиторий `MADTeacher.github.io`,
ветка `main` деплоится автоматически).

## Железные правила

1. **Никакой сборки.** Не добавлять `package.json`, бандлеры, фреймворки,
   препроцессоры, TypeScript. Только HTML + CSS + vanilla JS. Это осознанное
   решение владельца, а не отсталость.
2. **Цвета – только через CSS-переменные** (`var(--bg)`, `var(--accent)` и т.д.)
   из `:root[data-theme="light"]` и `:root[data-theme="dark"]`. Сайт двухтемный:
   захардкоженный цвет ломает одну из тем.
3. **Имя владельца везде «Чернышев» – без «ё».** В тексте, alt, meta, README,
   генерируемых картинках.
4. **Контент сайта – на русском.**
5. **Тире – только среднее (en dash, «–»), не длинное (em dash, «—»).** Во всех
   текстах: контент сайта, README, комментарии в коде, генерируемые картинки.
   Длинное тире в тексте – ошибка, заменить на среднее.
6. **Не выдумывать факты.** Описания книг, ссылки, цифры, фамилии соавторов –
   только из проверенных источников: README книжных репозиториев
   (`github.com/MADTeacher/*`), посты Boosty/Sponsr, карточки товаров «Питера»,
   слова владельца. Данных нет – спросить владельца, не сочинять.
   (Это правило появилось после инцидентов с выдуманными описаниями книг.)
7. **`assets/photo_src.jpg` не коммитить** – он в `.gitignore`, это тяжёлый
   исходник портрета; генерация работает с локальной копией.
8. **PowerShell-скрипты – UTF-8 с BOM.** Без BOM Windows PowerShell 5.1
   неправильно читает кириллицу в строках (ломает og-image).
9. Коммитить только по просьбе владельца.

## Где что лежит

| Путь | Смысл |
|---|---|
| `index.html` | Весь контент: шапка, биография, книги, курсы, публикации, каналы. Карточки книг и курсов – `<article class="card">`, статьи – `<ol class="pub-list">` (в комментариях есть шаблоны) |
| `css/style.css` | Темы и вёрстка. Новые стили – с учётом обеих тем |
| `js/main.js` | Переключатель темы, год в подвале, внешние ссылки в отдельной вкладке и ThumbHash-заглушки обложек |
| `js/vendor/thumbhash.js` | Вендорский декодер ThumbHash (MIT, © Evan Wallace) – не редактировать |
| `assets/covers/` | Обложки книг для карточек (готовые WebP, ≤480px) |
| `assets/covers/src/` | Исходники обложек – пересжимаются скриптом, напрямую на сайт не ссылаются |
| `tools/make-og.ps1` | Генерирует `portrait.webp`, `avatar.jpg`, `og-image.png`, иконки из `assets/photo_src.jpg` |
| `tools/resize-covers.ps1` | Пересжимает всё из `assets/covers/src/` в `assets/covers/` (480px, WebP q85) и печатает `data-thumbhash` для карточек |
| `tools/webp-lib.ps1` | Общая библиотека для скриптов: поиск WebP-кодировщика (cwebp/magick/ffmpeg), кодирование и расчёт ThumbHash |
| `tools/montage.ps1` | Склеивает набор картинок (jpg/png/webp) в один контрольный лист (для визуальной проверки) |

## Типовые задачи

- **Добавить книгу:** скопировать карточку в `index.html`; обложку положить в
  `assets/covers/src/<имя>.jpg`, прогнать `resize-covers.ps1`, сослаться на
  `assets/covers/<имя>.webp` с указанием width/height и вставить напечатанный
  скриптом `data-thumbhash` в `<img>` обложки.
- **Добавить курс Stepik:** скопировать шаблон `<article class="card">` из
  комментария в секции `id="courses"`; ссылка вида `https://stepik.org/a/<id>`;
  описание брать из карточки курса на Stepik, **цены и число учеников на сайт
  не ставить** (протухают).
- **Добавить статью ВАК:** скопировать шаблон `<li>` из комментария в секции
  `id="publications"`.
- **Обложка с Boosty:** у поста нет og:image с обложкой – вытащить список
  `https://images.boosty.to/image/<id>` из HTML поста (curl), скачать,
  **обязательно проверить визуально** (контрольный лист через `montage.ps1`),
  что это обложка, а не промо-баннер Boosty или скан внутренних страниц.
- **Сменить фото владельца:** заменить `assets/photo_src.jpg`, прогнать
  `make-og.ps1` (в скрипте зашиты координаты лица под конкретный исходник –
  при заметно другом кадре поправить `$cropX` и кроп) и обновить
  `data-thumbhash` у портрета в `index.html` – скрипт печатает новое значение.

## Проверка после правок

- Открыть `index.html` в браузере в **обеих темах** (переключатель в шапке).
- После генерации картинок – собрать `montage.ps1` и посмотреть глазами:
  текст не обрезан, не наезжает, кириллица не кракозябрами.
- Прокликать ссылки, которые менял.
